Project 1: Data Cleaning and Preparation

Overview

This project involved cleaning and preparing a dataset using Microsoft Excel as part of my DecodeLabs Data Analytics Internship.

Objective

To inspect the raw dataset, identify data quality issues, handle missing values appropriately, check for duplicates, and validate calculated values to prepare the data for reliable analysis.

Tool Used

* Microsoft Excel

Dataset Description

* Number of rows: 1,200
* Number of columns: 14
* Missing values identified: 309 blank cells in the CouponCode column

Data Cleaning Process

1. Data Inspection

Inspected the dataset to understand its structure and identify potential data quality issues.

2. Handling Missing Values

Identified 309 blank values in the CouponCode column and reviewed how they should be handled based on their meaning.

3. Duplicate Check

Checked the OrderID column for duplicate values. No duplicate OrderIDs were found.

4. Data Validation

Compared TotalPrice with Quantity multiplied by UnitPrice. The values matched to two decimal places.

Key Findings

* The dataset contained 1,200 rows and 14 columns.
* The CouponCode column contained 309 blank values that required review.
* No duplicate OrderIDs were identified.
* TotalPrice values were consistent with Quantity multiplied by UnitPrice to two decimal places.

Outcome

The data inspection and validation process helped identify missing values, check record uniqueness, and verify price calculations before further analysis.

Skills Demonstrated

* Data inspection
* Missing-value assessment
* Duplicate checking
* Data validation
* Microsoft Excel

Conclusion

This project strengthened my practical understanding of data quality checks and the importance of preparing reliable data before performing analysis or creating visualizations.
