DecodeLabs Data Analytics Internship – Project 2: Exploratory Data Analysis (EDA)

I’m excited to share my progress on my second data analytics project, where I performed Exploratory Data Analysis (EDA) using Microsoft Excel.
The objective was to explore the dataset, calculate descriptive statistics, identify trends and outliers, and communicate meaningful insights.

Project Highlights & Key Figures
* 1,200 total records analyzed.
* 14 columns in the dataset.
* 309 missing values identified in the CouponCode column.
* 0 duplicate OrderIDs found.
* 1,053.97 mean order value.
* 823.615 median order value.
* 8 potential high-value outliers identified using the Interquartile Range (IQR) method.
* 3,330.4075 upper outlier boundary.

🛠️ Tools & Techniques Used
* Microsoft Excel
* Descriptive Statistics (Mean, Median and Count)
* PivotTables and PivotCharts
* Trend Analysis
* Outlier Detection (IQR Method)
* Data Interpretation

Key Learning
This project strengthened my understanding of how to examine datasets, recognize unusual patterns, interpret statistical results, and turn raw data into meaningful insights.
